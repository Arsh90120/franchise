# 🏀 Franchise

**AI-powered browser basketball GM sim.** Real NBA players, real drama, deep front office control.

Built with Next.js 14, BallDontLie API, and NVIDIA NIM (Llama 3.3 70B).

## Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **State:** Zustand (persisted to localStorage)
- **Player Data:** BallDontLie API
- **AI:** NVIDIA NIM — `meta/llama-3.3-70b-instruct`
- **Deployment:** Vercel

- [x] Phase 1 — Scaffold, design system, API layer
